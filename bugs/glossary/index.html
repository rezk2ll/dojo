Glossaire

:=
La déclaration courte de Go. Dans un nouveau bloc, elle déclare tous les noms à sa gauche, même si une variable de ce nom existe hors du bloc.
La fonction d’annulation qui reste nil
`%` en C
Le reste d’une division entière. Son signe suit l’opérande de gauche : -7 % 3 vaut -1, et -6 % 3 vaut 0.
Un reste de zéro
`argv[2]`
Le troisième mot de la commande. Pour MOVE key 5, c’est la chaîne "5".
Une base nommée notanumber
`atoi`
Une fonction C qui transforme le début d’une chaîne en int. Elle s’arrête au premier caractère qui n’est pas un chiffre, et renvoie 0 s’il n’y a aucun nombre. Elle ne signale jamais d’erreur.
Une base nommée notanumber
`Date.new(year, month, -1)`
En Ruby, le jour -1 désigne le dernier jour du mois. .day donne alors le nombre de jours du mois.
Le dernier jeudi de février
`drain`
Lance tous les jobs en attente d’une classe de worker jusqu’à ce qu’il n’en reste aucun. drain_all fait de même pour toutes les classes.
drain_all de Sidekiq boucle sur un job hors de sa file par défaut
`IMPLEMENT_var_keylen_cipher`
Arguments de la macro, dans l’ordre : algorithme, nom en majuscules, mode, mode en majuscules, flags, bits de clé, bits de bloc, bits d’IV, bloc ou flux. Les bits de clé donnent la longueur de clé par défaut et le nom de la table, comme dans cast5128cbc_functions.
CAST5 en CFB et OFB prend une clé de 8 octets par défaut
`selectDb`
Place le client sur la base id. Elle ne renvoie REDIS_ERR que si id est sous 0 ou pas sous le nombre de bases (16 par défaut).
Une base nommée notanumber
`sigchain_push_common`
Pose le même handler pour SIGINT, SIGHUP, SIGTERM, SIGQUIT et SIGPIPE.
Deux handlers de signal posés dans le mauvais ordre
AbortSignal
Un objet que tu passes à fetch dans signal. Quand il se déclenche, le fetch s’arrête et sa promesse est rejetée.
Un fetch sans timeout
Alias
Un nom dans la table [alias] d’une config Cargo qui se déplie en une autre commande, ici cargo foo en cargo a b.
Une erreur de parsing de config affichée comme commande inconnue
asyncio.gather
Prend plusieurs tâches et renvoie un seul future, terminé quand toutes le sont. Le code l’attend avec await.
Un await manquant devant asyncio.gather
Auto-commit
Un mode de connexion où chaque requête est validée seule. L’incrémenteur le coupe pour faire le commit à la main.
Une connexion jamais fermée, à cause d’un throw dans finally
Backtracking
Quand une partie de la regex échoue, le moteur revient en arrière et essaie une autre façon de faire correspondre les parties d’avant.
Le backtracking d’une regex sur un e-mail trop court
Binding
bind:currentTime={x} garde x et la position de lecture synchronisés, dans les deux sens. set écrit la position dans x.
Un écouteur timeupdate resté sur un élément audio retiré
Bit de flag
Un bit de l’en-tête de l’objet qui note un fait sur lui, testé avec flags & SOME_FLAG.
Des hashs jamais libérés
BOM
Byte order mark : le caractère U+FEFF que certains éditeurs écrivent tout au début d’un fichier UTF-8. Il est invisible, mais compte pour un caractère dans une chaîne JavaScript.
Les offsets après le retrait d’un BOM
BYDAY
La partie d’une règle de répétition (RRULE) qui nomme le jour. BYDAY=4TH est le quatrième jeudi, BYDAY=-1TH le dernier.
Le dernier jeudi de février
CAST5
Un chiffrement par bloc avec des blocs de 64 bits et des clés de 5 à 16 octets. Sa clé normale fait 16 octets (128 bits).
CAST5 en CFB et OFB prend une clé de 8 octets par défaut
Centimes
La plus petite unité du prix. Stripe veut unit_amount en nombre entier de centimes : 19,99 $ donne 1999.
Erreur de virgule flottante dans la conversion des dollars en centimes
Clé de cache
La chaîne sous laquelle une valeur est rangée. Deux bouts de code qui construisent la même clé lisent et écrivent la même valeur.
Une clé de rate limit sans le contrôleur
Closure
Une fonction littérale qui utilise des variables du code autour d’elle. Elle lit la variable elle-même, pas une copie.
Une variable de boucle capturée par une goroutine
Coercition de type
JavaScript qui convertit tout seul une valeur vers un autre type, par exemple un tableau en chaîne.
Un tableau qui passe pour une sévérité
Colonne
Une position dans une ligne. Le parseur HTML qu’utilise Vite compte les colonnes à partir de 1.
Décalage d’un entre une colonne et un offset
Condition de sortie
Le test qu’une boucle vérifie avant chaque tour, ici jobs.any?. La boucle ne s’arrête que si le corps le rend faux.
