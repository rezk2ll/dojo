Glossaire

`usage`
L’objet présent dans chaque réponse de la Messages API, qui compte les tokens de la requête par catégorie. Anthropic facture chaque requête à partir de ces nombres.
Coût et latence
Agent
La définition d’Anthropic : un système où les modèles "dynamically direct their own processes and tool usage" (pilotent eux-mêmes leur démarche et leurs outils). En code, un modèle qui appelle des outils en boucle jusqu’à ce qu’une condition d’arrêt soit remplie.
La boucle d’agent
Ancrage
Mettre le texte source dans le contexte et demander au modèle de répondre uniquement à partir de lui, en citant.
Sûr de lui et faux
API inventée
Un appel à une fonction, un paramètre, une option ou un paquet qui n’existe pas dans la version que tu utilises. Le code se lit bien et plante à l’exécution.

Appel d’outil
Une demande du modèle pour lancer un outil intégré, comme Read, Edit ou Bash, avec ses paramètres. Claude Code l’exécute et renvoie le résultat au modèle.
Une session de Claude Code
Balise de sortie
Une balise dans laquelle tu demandes au modèle de mettre sa réponse, pour que ton code la retrouve en cherchant cette balise.

Un nom entre chevrons placé autour d’un bloc de texte, comme <ticket> et </ticket>. Le modèle lit ce nom comme l’étiquette du bloc.

Un juge qui préfère une réponse à cause de sa place dans le prompt (première ou seconde), quel que soit son contenu.

Bloc de contenu
Un élément d’un tableau content, avec un type comme text, image, tool_use ou thinking. Une simple chaîne en content est un raccourci pour un seul bloc text.

Un bloc de contenu thinking qui arrive avant les blocs text. Il contient un résumé du raisonnement, ou une chaîne vide, plus une signature chiffrée.

Bloc tool_result
Un bloc de contenu que tu renvoies dans un message user, avec le tool_use_id auquel il répond, le résultat dans content, et is_error: true si l’outil a échoué.

Bloc tool_use
Un bloc de contenu dans la réponse du modèle, avec un id, le name de l’outil et un objet input. C’est une demande adressée à ton code : lance cet outil.
L’appel d’outils
BM25
Une fonction de classement fondée sur TF-IDF, qui note les morceaux selon les mots exacts qu’ils partagent avec la requête. Elle trouve une chaîne comme "TS-999" qu’une recherche par embeddings peut rater.

Byte pair encoding : on part des 256 valeurs d’octet, puis on donne à chaque tour un nouvel identifiant à la paire de voisins la plus fréquente.

Stateless
L’API ne garde aucune conversation entre deux appels. Chaque requête porte tout l’historique que le modèle doit voir, et rien d’autre ne lui parvient.

Taux d’accord
La part des cas où deux correcteurs donnent le même verdict. Tu le calcules entre le juge et des humains, et entre deux humains.

Température
Le nombre par lequel on divise les logits avant le softmax. En dessous de 1, les probabilités se resserrent sur le meilleur token ; au-dessus de 1, elles s’aplatissent.

Un test qui passe encore quand le code qu’il devrait vérifier est cassé ou supprimé.
Relire du code écrit par une IA
Token
Une unité de texte que le modèle lit ou écrit, stockée sous forme d’identifiant entier. Un token peut être un octet, quelques lettres ou un mot entier avec son espace devant.
Les tokens
Tokenizer
Le programme qui transforme le texte en liste d’identifiants de tokens avant que le modèle le voie, et qui refait du texte à partir des identifiants après.
Les tokens
Tokens d’entrée
Tous les tokens que tu envoies dans une requête : prompt système, tours précédents, documents, définitions d’outils et la question.
Coût et latence
Tokens de sortie
Tous les tokens que le modèle génère dans sa réponse, réflexion comprise. Sur tous les modèles Claude actuels, un token de sortie coûte 5 fois un token d’entrée.
Coût et latence
Tour
Un aller-retour : le modèle demande des appels d’outils, les outils tournent, et les résultats repartent vers lui. La boucle s’arrête quand le modèle répond par du texte sans appel d’outil.
Une session de Claude Code
Tour utilisateur
Un message avec role: "user" dans le tableau messages : une question, un fichier collé, une liste de résultats d’outils.
Prompt système et rôles
Transport
Le chemin des messages JSON-RPC : stdio (un message par ligne sur le stdin et le stdout d’un sous-processus) ou Streamable HTTP (chaque message est un POST vers un seul endpoint).
Model Context Protocol
TTFT
Time to first token : le temps entre l’envoi de la requête et la réception du premier token de la réponse. Ton code ne peut le mesurer que sur une réponse en streaming.
Coût et latence
TTL
La durée de vie d’une entrée de cache : 5 minutes par défaut, ou 1 heure avec une écriture plus chère. Chaque lecture renouvelle l’entrée pour 5 minutes de plus, sans surcoût.
Le prompt caching
Type de résultat
Chaque requête finit dans l’un de quatre états : succeeded, errored, canceled ou expired. Seul succeeded est facturé.

Vocabulaire
La table complète des identifiants que connaît un tokenizer. Dans minbpe, sa taille vaut 256 plus le nombre de fusions.
