The --bare flag: Claude Code skips hooks, skills, plugins, MCP servers, auto memory and CLAUDE.md that it would otherwise find on the machine. It needs ANTHROPIC_API_KEY, because it never reads your subscription login.

BM25
A ranking function based on TF-IDF that scores chunks by exact word matches. It finds a string like "TS-999" that an embedding search can miss.

BPE
Byte pair encoding: start from the 256 byte values, then repeatedly give the most frequent pair of neighbouring ids a new id.

Contextual Retrieval

Result type

Examples chosen for each input at request time, by searching a labeled set for the entries closest to that input.

RLHF
Reinforcement learning from human feedback: people rank model answers, a reward model learns to predict those rankings, and the model is trained to get a high reward.
