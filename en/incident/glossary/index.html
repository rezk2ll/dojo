active-active
A service runs and serves traffic in several datacenters at once, so one datacenter can fail while the others keep answering.
Square 2017: retries that overloaded merchant authentication
Admission webhook
An HTTP call the API server makes to another service before it accepts a write. If that service does not answer, the write times out.
Reddit 2023: the Kubernetes upgrade that removed a node label
Anycast
Announcing the same prefix from many data centers, so each user reaches the nearest one. Cloudflare serves almost all its services this way.
Cloudflare 1.1.1.1 2025: the resolver prefixes withdrawn by a test change
API key
A secret string that a script sends to a service, here Cloudflare, to make changes without a person logging in.

apiserver
The Kubernetes process that every other component asks for the cluster’s state. It reads and writes that state in etcd.
Monzo 2017: linkerd, Kubernetes and a payments outage
Approximate top-k
A fast operation that finds the k highest values in an array and may be wrong on the lowest ones it returns. JAX's version, jax.lax.approx_max_k, has a default recall_target of 0.95.
Anthropic 2025: three bugs that degraded Claude's answers
Authoritative name server
The DNS server that holds the answers for a domain. Facebook's run at fixed IP addresses that Facebook advertises with BGP.
Facebook 2021: the backbone that took its own DNS offline
Authorization
Boulder's record that an account proved control of one domain name. Let's Encrypt reuses it for 30 days.

authorized_keys
The file on a server that lists the SSH public keys allowed to log in to an account. By default, sshd also reads the legacy file authorized_keys2.

Backbone

Backoff
A client waits longer after each failed try before it retries. Without it, retries add load to a system that is already failing.

backoff
A wait before each retry, usually longer after each failure, so retries do not hit the server as fast as the client can send them.

Backtracking
What a regex engine like PCRE does when a match fails: it goes back and tries another way to split the input. Some patterns make it try a very large number of ways.

Baseline Requirements (BRs)

Bash Uploader

BGP
The protocol networks use to announce which IP blocks they can reach. Google announces each GCE IP block from several sites, so users take the shortest path.

BGP
