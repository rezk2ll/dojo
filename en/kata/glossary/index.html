Glossary

302 Found
The HTTP status that tells the browser the target is temporary. The browser follows the Location header and keeps using the short URL next time.
A URL shortener
429 Too Many Requests
The HTTP status for a client that sent too many requests in a given time. It may carry a Retry-After header saying when to try again.
A rate limiter
Anchor
A copy of the latest hash written to a place the database admins cannot change, used later to check the chain.
An audit log
At-least-once
A sender retries until it gets an acknowledgement, so the receiver may see the same event more than once.
Notifications
At-least-once
Each job runs one or more times. A crash can make it run again, and it never runs zero times.
A job scheduler
At-least-once delivery
Every event reaches the customer one or more times: the sender retries until it gets a 2xx, so the customer can get a copy twice.
Webhook delivery
Authorize and capture
Two card calls: the authorization holds the amount on the card, the capture takes the money later.
An order across services
Backfill
A job that fills a new column for rows that existed before it, in small batches.
Deploying without downtime
Backlog
The jobs waiting in the queue that no worker has taken yet.
A queue that fills up
Backpressure
A signal from the consumer side back to the producer that says "send less", so the backlog stops growing.
A queue that fills up
Base62
Writing a value with the 62 characters 0-9, a-z and A-Z. A code of n characters has 62 to the power n possible values.
A URL shortener
Binlog
The MySQL binary log: every committed change, in commit order. MySQL uses it for replication.
Moving to a new database
Block
A fixed-size slice of a file, named by the hash of its bytes, so two devices can compare files block by block.
File sync
Breaking change
A change after which code that worked against the API stops working: a removed field, a renamed field, a field with a new type.
Changing a public API
Burn rate
How fast the service spends its error budget. A burn rate of 1 spends exactly the whole budget in the 30-day window.
Measuring a service
Capped list
A list trimmed to a fixed length after each insert, so it keeps only the newest entries.
An activity feed
Central authority
The one process that decides, for one document, the order in which steps are applied.
Shared document editing
Change data capture (CDC)
Reading a database’s log of changes and sending each change somewhere else as an event.
Moving to a new database
Channel
One way to reach a user: email, push to a phone, or the list of notifications inside the app.
Notifications
Check
The question "does user U have relation R on object O?", answered by following tuples from O to U.
A permissions system
Circuit breaker
A wrapper around a call that counts recent failures. Above a threshold it stops making the call for a while and fails at once, so the caller goes straight to its fallback.
When a dependency is down
Collapse id
The APNs header apns-collapse-id. Push requests with the same value show as one notification on the phone.
Notifications
Compensating transaction
The step that undoes an earlier one: release the reserved stock, cancel the card authorization.
An order across services
Completion suggester
An Elasticsearch feature that returns indexed inputs starting with a given prefix, from a structure kept in memory.
Search autocomplete
Conditional update
An UPDATE whose WHERE clause states the row must still be free. The returned row count tells you whether you got it.
Booking concert tickets
Conflict
Two revisions made from the same parent revision on two devices, which sync then puts side by side under one document id.
An offline-first mobile app
Conflict copy
The second version of a file, kept under a new name when two edits cannot be ordered.
File sync
Cutover
The moment the application stops writing to the old database and starts writing to the new one.
Moving to a new database
Dead row version
In PostgreSQL, the old copy of a deleted or updated row. It keeps its disk space until VACUUM marks that space free for reuse.
A paste service
Deadlock
Two transactions each hold a lock the other one waits for, so neither can finish.
Booking concert tickets
Debounce
The client waits a short time after the last keystroke and sends one request for the text at that moment.
Search autocomplete
Delivery
One row meaning "tell this user about this event on this channel". Its key is (event_id, user_id, channel).
Notifications
DNS rebinding
A domain answers with a public IP when you check it, then with an internal IP when you connect.
Link previews
Epoch
The moment the timestamp part of an id counts from. Snowflake counted from November 2010 instead of 1970, so the 41 bits last longer.
Unique ids across servers
Error budget
The failures the SLO allows in its window. At 99.9%, it is 0.1% of the requests.

Event notification
A message the storage service sends when an object is created in a bucket. Here it goes to a queue.

Expand and contract
A schema change split into steps. First add the new shape next to the old one, then move code and data to it, and only then remove the old shape.

Expired event

Online status
Expiry time
The moment after which a paste must no longer be served. The author picks it when creating the paste.
A paste service
Exponential backoff
Each retry waits twice as long as the previous one, starting at 1 minute.
Webhook delivery
Fail open
When the limiter itself is down, let requests through instead of refusing them all.
A rate limiter
Fallback
What the code returns when a call fails or times out, like a stored list of best sellers instead of personal recommendations.

Gateway
