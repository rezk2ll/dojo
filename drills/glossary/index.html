Glossaire

-print0
Une action de find qui affiche chaque nom de fichier suivi d’un caractère nul au lieu d’un saut de ligne.
xargs
\copy
La méta-commande psql qui déplace des lignes entre une table et un fichier sur la machine où tourne psql, ici ton portable.
psql
`--`
Un séparateur sur la ligne de commande. Git lit chaque mot placé après comme un chemin, jamais comme une option ou un nom de branche.
Lire l’historique
`<rev>:<path>`
Le fichier <path> tel qu’il était enregistré dans le commit <rev>, par exemple HEAD~2:src/config.js.
Retrouver des choses dans git
`A..B`
Les commits atteignables depuis B qui ne le sont pas depuis A. A lui-même n’en fait pas partie.
Rebase et cherry-pick
`stash@{n}`
Le nom d’une entrée : stash@{0} est la plus récente, stash@{1} la précédente. Tu peux aussi écrire le simple numéro n.
Le stash
Active
L’état d’une unit à l’exécution : active quand le service tourne, inactive quand il est arrêté, failed quand il s’est terminé en erreur.
systemctl
Adresse
La partie placée avant une commande sed, qui choisit les lignes où elle s’applique : un numéro comme 2, une regex comme /^#/, ou un intervalle comme 2,4.
sed
Affectation par mise à jour
|= dans un filtre. Il passe l’ancienne valeur d’un champ dans un filtre et range le résultat au même endroit.
Transformer avec jq
alias de table
Un nom court pour une table le temps d’une requête, comme c dans customers c. Une auto-jointure a besoin de deux alias pour la même table.
Les jointures
ancre
Une partie de regex qui correspond à une position et pas à un caractère : ^ est le début de l’entrée, $ la fin et \b une limite de mot.
Les bases des regex
base de fusion
Le commit le plus récent que deux branches ont en commun : le point où feature/pdf a quitté main.
Voir les changements
bastion
Un hôte qui accepte le SSH depuis l’extérieur et par lequel tu passes pour joindre les hôtes derrière lui.
ssh et scp
bisect
Une recherche dichotomique dans l’historique. Tu marques un commit mauvais et un bon, et Git extrait le commit à mi-chemin pour que tu le testes.
Retrouver des choses dans git
bloc de transaction
Les requêtes entre BEGIN et COMMIT. Certaines commandes, comme CREATE INDEX CONCURRENTLY, refusent de s’y exécuter.
Tables et index
Boot
La période entre un démarrage de la machine et le suivant. -b -1 désigne le boot d’avant, -b seul le boot en cours.
journalctl
branche
Un nom qui pointe vers un commit. Chaque nouveau commit sur la branche fait avancer ce nom jusqu’à lui.
Les branches
branche amont
La branche distante à laquelle une branche locale est liée. Un simple git push ou git pull sur cette branche l’utilise.
Les remotes
branche de suivi distante
Ta copie locale d’une branche d’un dépôt distant, comme origin/fix/tax-tests. git fetch la met à jour.
Les branches
branche de suivi distante
Une copie locale d’une branche d’un remote, comme origin/main. git fetch la met à jour ; tu ne commites pas dessus.
Les remotes
caractère de mot
Une lettre, un chiffre ou _. -w s’en sert pour savoir où un mot commence et finit.
Chercher dans du texte
caractère nul
L’octet de valeur 0. find -print0 et xargs -0 s’en servent pour séparer les noms de fichiers : une espace ou un saut de ligne dans un nom reste dans le nom.
xargs
champ
Une colonne d’une ligne. Par défaut, sort coupe les champs là où commencent les blancs ; -t choisit un autre séparateur.
Trier et compter
Champ
Un morceau de ligne une fois qu’awk l’a coupée. $1 est le premier champ, et $0 contient la ligne complète.
awk
cherry-pick
Git applique le changement d’un commit existant au-dessus de la branche courante et l’enregistre comme un nouveau commit, avec un nouveau hash.
Rebase et cherry-pick
cible du conflit
La liste de colonnes après ON CONFLICT, par exemple (sku). PostgreSQL s’en sert pour choisir l’index unique qui décide ce qui compte comme doublon.
Modifier les données
classe de caractères
Un ensemble de caractères qui correspond à un seul caractère, comme [0-9], son raccourci \d, ou [^ ] pour tout caractère sauf l’espace.
Les bases des regex
clé de tri
La partie de chaque ligne que sort compare, choisie avec -k. Sans -k, sort compare les lignes entières.
Trier et compter
clé étrangère
Une contrainte qui n’accepte dans une colonne que des valeurs présentes dans une colonne d’une autre table, ici tickets.user_id et users.id.
Tables et index
COALESCE
Une fonction qui rend le premier de ses arguments qui n’est pas NULL, comme COALESCE(phone, 'none').
NULL dans les requêtes
Code de sortie
Le nombre que curl rend au shell en se terminant. 0 veut dire que le transfert a marché, 22 veut dire que --fail a vu un statut de 400 ou plus.
curl
Code de statut
Le nombre à trois chiffres sur la première ligne de la réponse : 200 pour OK, 301 pour déplacé, 404 pour introuvable.
curl
condition de jointure
Le test après ON, comme o.customer_id = c.id. Une paire de lignes entre dans le résultat quand il est vrai.
Les jointures
Construction d’objet
{...} dans un filtre. Il fabrique un nouvel objet, comme {name: .service}, à partir des champs de l’entrée.
Transformer avec jq
Conteneur
Un processus lancé à partir d’une image, avec son propre système de fichiers et un nom, comme web. Il reste sur le disque après son arrêt, jusqu’à ce que tu le supprimes.
docker
conteneur
Un processus avec sa propre image, dans un pod. Dans un pod à deux conteneurs, -c dit lequel tu vises.
kubectl pour déboguer
contexte de build
Le dossier que tu passes à docker build. COPY ne lit que des fichiers de ce dossier.
Les lignes d’un Dockerfile
contrainte
Une règle sur une colonne ou une table que PostgreSQL vérifie à chaque insertion et mise à jour, comme NOT NULL, UNIQUE, CHECK ou une clé étrangère.
Tables et index
copie de travail
Les fichiers sur ton disque, tels que tu les modifies.
Voir les changements
correspondance
Une ligne qui contient le motif. Par défaut, grep affiche chaque correspondance et rien d’autre.
Chercher dans du texte
couche
Les changements de fichiers qu’une instruction ajoute à l’image. Quand une couche change, Docker la reconstruit, ainsi que toutes les couches suivantes.
Les lignes d’un Dockerfile
CrashLoopBackOff
Le statut que kubectl affiche pour un conteneur qui plante sans cesse. Le kubelet attend 10 s, 20 s, 40 s et ainsi de suite entre deux redémarrages, jusqu’à 5 minutes.
kubectl pour déboguer
CRLF
Une fin de ligne faite d’un retour chariot (\r) et d’un saut de ligne (\n). cut ne coupe les lignes que sur le saut de ligne, donc le \r reste collé à la fin du dernier champ.
Découper des colonnes
CSR
Demande de signature de certificat (PKCS#10) : un fichier qui contient ta clé publique et le sujet demandé, signé avec ta propre clé privée.
openssl pour TLS
délimiteur
Le caractère qui sépare les champs d’une ligne, comme : dans passwd.txt. cut -d le choisit ; par défaut, c’est une tabulation.
Découper des colonnes
Délimiteur
Le caractère qui sépare les parties de s/REGEXP/REPLACEMENT/. C’est / par défaut, et ça peut être n’importe quel autre caractère.
sed
descripteur de fichier
Le numéro que le shell donne à chaque flux ouvert d’une commande : 0 pour l’entrée standard, 1 pour la sortie standard, 2 pour la sortie d’erreur.
Pipes et redirections
diffstat
Une ligne par fichier modifié avec le nombre de lignes changées, puis un total comme 1 file changed, 2 insertions(+).
Lire l’historique
élément
Un mot que xargs lit sur l’entrée standard. Par défaut, les blancs et les sauts de ligne séparent les éléments : cache 1.tmp en donne 2.
xargs
En-tête
Une ligne Nom: valeur envoyée avant le corps, par le client dans la requête ou par le serveur dans la réponse.
curl
Enabled
Une unit est enabled quand systemd a créé les liens symboliques décrits dans sa section [Install], pour qu’elle démarre au boot.
systemctl
enregistrement A
Un enregistrement DNS qui associe un nom à une adresse IPv4. dig le demande quand tu ne donnes aucun type.
Vérifications réseau
Entrée (entry)
Une clé et sa valeur, que to_entries écrit sous la forme {"key": ..., "value": ...}.
Transformer avec jq
entrée de stash
Un lot de changements non commités mis de côté, avec un message. git stash push en ajoute une et remet l’arbre de travail et l’index à l’état de HEAD.
Le stash
EXCLUDED
Un nom de table spécial dans ON CONFLICT DO UPDATE. Il contient la ligne que l’INSERT a essayé d’ajouter.
Modifier les données
Fichier d’unit
Le fichier texte qui définit une unit, comme /etc/systemd/system/orders.service, avec des sections comme [Service] et [Install].
systemctl
fichier non suivi
Un fichier de l’arbre de travail qui n’est jamais passé par git add. git status --short le marque ??.
Le stash
Filtre
Le programme jq que tu passes entre guillemets, comme .services[0]. Il prend du JSON en entrée et sort du JSON.
Les bases de jq
fonction d’agrégat
Une fonction comme count, sum ou avg qui lit plusieurs lignes et rend une seule valeur.
Compter en SQL
forme exec
Une instruction écrite comme un tableau JSON, par exemple CMD ["node", "server.js"]. Docker lance le programme directement, sans /bin/sh -c autour.
Les lignes d’un Dockerfile
fusionnée
Une branche est fusionnée dans main quand son dernier commit est atteignable depuis main : la supprimer ne fait perdre aucun commit.
Les branches
glob
Un motif du shell où * remplace n’importe quelle suite de caractères et ? un seul caractère, comme *.log.
Trouver des fichiers
groupe
L’ensemble des lignes qui ont les mêmes valeurs dans les colonnes du GROUP BY. La requête rend une ligne par groupe.
Compter en SQL
Groupe capturant
(...) dans une regex. Il garde le texte trouvé, numéroté 1, 2, 3 dans l’ordre des parenthèses ouvrantes.
Les groupes en regex
Groupe non capturant
(?:...) dans une regex. Il regroupe une partie du motif pour | ou un quantificateur, sans rien garder.
Les groupes en regex
hash court
Les premiers caractères de l’identifiant de 40 caractères d’un commit, assez pour le désigner sans ambiguïté dans ce dépôt.
Lire l’historique
HAVING
Une condition testée sur chaque groupe, une fois les agrégats calculés. Une condition WHERE porte sur chaque ligne, avant le regroupement.
Compter en SQL
HEAD
Le commit sur lequel tu es. Sur une branche, c’est son commit le plus récent, et HEAD~2 est son grand-parent en suivant les premiers parents.
Annuler
here string
L’opérateur <<< : le shell passe un mot, suivi d’un retour à la ligne, sur l’entrée standard de la commande.
Pipes et redirections
Image
Un modèle en lecture seule avec un nom et un tag, comme nginx:1.27. docker run en crée un conteneur.
docker
index
La zone de préparation : l’instantané des fichiers que git commit va enregistrer. git add y copie un fichier depuis la copie de travail.
Voir les changements
index
La zone de préparation : ce que contiendra le prochain commit. git add y copie un fichier.
Annuler
Itérateur
.[], qui sort chaque élément d’un tableau comme un résultat séparé. .services[] donne 3 objets, l’un après l’autre.
Les bases de jq
job
Une commande que bash a lancée depuis ce terminal, numérotée à partir de 1. jobs les liste et %1 désigne le job 1.
Processus
Journal
Le stockage des logs de systemd, écrit par journald. Chaque entrée a un message et des champs ; _SYSTEMD_UNIT contient le nom de l’unit.
journalctl
JSONPath
Un chemin vers un champ d’un objet, comme .status.podIP. -o jsonpath et --sort-by en prennent un.
kubectl get et describe
label
Une clé et une valeur posées sur un objet, comme app=web. Un sélecteur de labels retient tous les objets qui l’ont.
kubectl get et describe
LEFT JOIN
Une jointure qui garde chaque ligne de la table de gauche. Quand aucune ligne de droite ne correspond, les colonnes de droite valent NULL.
Les jointures
lignes adjacentes
Des lignes qui se suivent. uniq ne fusionne des lignes égales que si elles sont adjacentes.
Trier et compter
liste du SELECT
Les expressions entre SELECT et FROM. Chacune donne une colonne du résultat.
Les bases de SELECT
méta-commande
Une commande psql qui commence par une barre oblique inverse, comme \dt. psql l’exécute lui-même et ne l’envoie jamais au serveur.
psql
Méthode
Le verbe au début d’une requête HTTP : GET, HEAD, POST, DELETE. curl envoie GET tant qu’aucune option ne le change.
curl
mode
Les 9 bits de permission d’un fichier : lecture, écriture et exécution pour le propriétaire, pour le groupe et pour tous les autres.
Les permissions
mode octal
Le mode écrit en chiffres, un par catégorie, chacun la somme de lecture (4), écriture (2) et exécution (1). 640 vaut rw-r-----.
Les permissions
mode symbolique
Le mode écrit avec une catégorie, un opérateur et des lettres, comme u+x ou go-rwx. Il ne touche que les bits qu’il nomme.
Les permissions
motif
Le texte ou l’expression régulière que grep cherche dans chaque ligne, comme ERROR ou WARN|ERROR.
Chercher dans du texte
motif
Le texte à droite de LIKE. % correspond à n’importe quelle suite de caractères, même vide, et _ à un seul caractère.
Les bases de SELECT
Motif
Une condition placée avant {...}, comme $4 == 500. awk ne lance l’action que sur les lignes où elle est vraie.
awk
namespace
Un groupe nommé d’objets dans un cluster. kubectl cherche dans un seul namespace, sauf si tu en donnes un autre avec -n.
kubectl get et describe
NULL
Le marqueur d’une valeur absente. =, <> et les autres comparaisons rendent NULL quand un côté est NULL, et WHERE écarte une ligne dont la condition vaut NULL.
NULL dans les requêtes
NULLIF
Une fonction qui rend NULL quand ses 2 arguments sont égaux, et son premier argument sinon.
NULL dans les requêtes
OFFSET
Le nombre de lignes triées à sauter avant que LIMIT commence à compter les lignes renvoyées.
Les bases de SELECT
OVER
La clause placée juste après une fonction, qui en fait une fonction de fenêtrage. À l’intérieur, PARTITION BY et ORDER BY disent quelles lignes la fonction voit et dans quel ordre.
Les fonctions de fenêtrage
pair
Une ligne qui a la même valeur d’ORDER BY que la ligne courante, comme les ids 2 et 3 à 250 chacun.
Les fonctions de fenêtrage
paire de clés
Une clé privée qui reste sur ton portable et une clé publique, même nom de fichier avec .pub, que tu copies sur les serveurs.
ssh et scp
partition
Le groupe des lignes qui ont la même valeur de PARTITION BY, ici une par région. Sans PARTITION BY, tout le résultat forme une seule partition.
Les fonctions de fenêtrage
patch
Les lignes qu’un commit a ajoutées (préfixe +) et retirées (préfixe -), fichier par fichier.
Lire l’historique
Pattern space
Le tampon qui contient la ligne courante pendant que sed lui applique le script. sed l’affiche à la fin de chaque ligne, sauf avec -n.
sed
PEM
La forme texte d’un certificat ou d’une clé : du base64 entre des lignes comme -----BEGIN CERTIFICATE----- et -----END CERTIFICATE-----.
openssl pour TLS
pickaxe
Les options -S et -G de git log. Elles ne gardent que les commits dont le diff touche une chaîne ou une expression régulière donnée.
Retrouver des choses dans git
PID
L’identifiant de processus : le numéro que le noyau donne à chaque processus en cours, comme 4242.
Processus
pipe
L’opérateur | : il branche la sortie standard de la commande de gauche sur l’entrée standard de la commande de droite.
Pipes et redirections
Pipe
| dans un filtre. Il envoie chaque résultat de la partie gauche dans la partie droite, comme .services[] | .name.
Les bases de jq
plan
Les étapes que PostgreSQL choisit pour exécuter une requête, comme un parcours séquentiel de orders ou un parcours d’index. EXPLAIN l’affiche.
psql
point de départ
Le répertoire que tu donnes en premier à find, comme . ou logs. Il cherche dans ce répertoire et dans tout ce qu’il contient.
Trouver des fichiers
Port publié
Un port de l’hôte que Docker redirige vers un port du conteneur. -p 8080:80 envoie le port 8080 de l’hôte vers le port 80 du conteneur.
docker
Priorité
Le niveau syslog d’une entrée, de 0 (emerg) à 7 (debug). err vaut 3 et warning vaut 4.
journalctl
quantificateur
Un suffixe qui dit combien de fois l’élément qui le précède se répète : + pour 1 fois ou plus, * pour 0 fois ou plus, {4} pour exactement 4.
Les bases des regex
Quantificateur paresseux
Un quantificateur suivi de ?, comme *? ou +?. Il prend le moins de caractères possible.
Les groupes en regex
rebase
Git prend les commits d’une branche, les applique un par un au-dessus d’un autre commit, puis déplace la branche sur le dernier nouveau commit.
Rebase et cherry-pick
redirection de port locale
Un port de ton portable que ssh relie, à travers la connexion SSH, à un hôte et un port de l’autre côté.
ssh et scp
Référence arrière
\1 ou \k<name> dans un motif. Elle reconnaît le même texte que celui trouvé plus tôt par un groupe du motif.
Les groupes en regex
reflog
Un journal local de chaque commit vers lequel HEAD a pointé, du plus récent au plus ancien, numérotés HEAD@{0}, HEAD@{1} et ainsi de suite.
Annuler
remote
Un nom enregistré dans ton clone pour une autre copie du dépôt, avec son URL. origin est le remote que git clone crée.
Les remotes
résolveur
Le serveur DNS qui répond à tes requêtes. dig prend celui de /etc/resolv.conf, sauf si tu en nommes un autre avec @.
Vérifications réseau
RETURNING
Une clause à la fin d’un INSERT, d’un UPDATE ou d’un DELETE qui renvoie des colonnes des lignes modifiées.
Modifier les données
révision
Une version numérotée du modèle de pod d’un Deployment. Un changement du modèle, comme une nouvelle image, en crée une ; un changement d’échelle, non.
kubectl pour déboguer
SAN
Subject Alternative Name : une extension du certificat qui contient une liste de noms, comme DNS:www.shop.example.org.
openssl pour TLS
Séparateur de champs
Ce sur quoi awk coupe une ligne. Par défaut, les suites d’espaces et de tabulations ; -F, le règle sur la virgule.
awk
signal
Un message numéroté que le noyau remet à un processus. kill en envoie un ; SIGTERM vaut 15 et SIGKILL vaut 9.
Processus
SNI
Server Name Indication : le nom d’hôte que le client place dans son ClientHello, le premier message de la poignée de main TLS.
openssl pour TLS
socket en écoute
Un socket qui attend des connexions entrantes sur un port, comme celui qu’une base de données ouvre sur 5432.
Vérifications réseau
sortie d’erreur
Le descripteur 2, où ./build.sh écrit sa ligne error:. > et | la laissent sur le terminal tant que tu ne la déplaces pas.
Pipes et redirections
suivre
Ce que fait tail -f : il affiche les dernières lignes, garde le fichier ouvert et affiche chaque nouvelle ligne ajoutée.
Découper des colonnes
test
Une condition comme -name ou -size, vraie ou fausse pour chaque fichier. find n’affiche un fichier que si tous les tests sont vrais.
Trouver des fichiers
umask
Un masque gardé par le shell. Chaque bit présent dans le masque est retiré des fichiers et dossiers que créent les commandes de ce shell.
Les permissions
Unit
Un objet géré par systemd : un service, un timer, un socket, un point de montage. Son nom finit par son type, comme orders.service.
systemctl
upstream
La branche de suivi distante à laquelle une branche locale est liée. Sur cette branche, git status se compare à elle et un simple git pull tire depuis elle.
Les branches
